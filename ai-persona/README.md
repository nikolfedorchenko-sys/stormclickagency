# DAN – AI-ведучий YouTube-каналу новин

**DAN (Дан Шторм)** – AI-персонаж, який веде YouTube-канал про новини та найгарячіші події дня. Дан – цифровий двійник засновника каналу і не прикидається людиною: це штучний інтелект, який «прочитав усе, що сталося сьогодні», і за кілька хвилин віддає глядачу найважливіше й найцікавіше.

Цей каталог – повний «паспорт» персонажа: від характеру й зовнішності до промптів для генерації сценаріїв, картинок і голосу.

## Структура

## Швидкий старт

1. Прочитай `01-persona-bible.md` і `03-voice-and-style.md` – це ядро персонажа.
2. Згенеруй образ за промптами з `prompts/image-prompts.md` (або з готових налаштувань Higgsfield у `02-visual-identity.md`).
3. Налаштуй голос за `prompts/voice-tts.md`.
4. Збери добірку новин у JSON (приклад – `tools/news.example.json`).
5. Запусти генерацію сценарію:

```bash
cd ai-persona/tools
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python generate_episode.py --news news.example.json --format digest --out episode.md
```

6. Озвуч сценарій, згенеруй відео з аватаром, змонтуй за таймінгом із `prompts/script-template.md`.

## Виробничий конвеєр (щоденний)

```
Збір новин  →  Відбір (редактор)  →  generate_episode.py  →  Вичитка + факт-чек
     →  TTS (голос Дана)  →  Відео з аватаром  →  Монтаж + плашки  →  Обкладинка  →  Публікація
```

Кожен крок описаний у відповідному файлі. Жоден випуск не виходить без вичитки людиною – див. `05-editorial-policy.md`.
