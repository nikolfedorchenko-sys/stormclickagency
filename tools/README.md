# Інструменти

## fetch-law.js – тексти законів

Офіційний сайт zakon.rada.gov.ua з хмарного середовища не відповідає, тому тексти актів беремо з бази LIGA:ZAKON.

```
NODE_PATH=$(npm root -g) node tools/fetch-law.js <тека> <ID> [<ID> ...]
```

Тека – поза репозиторієм (тимчасова): тексти бази в git не зберігаємо. У середовищі має бути дозволена адреса `ips.ligazakon.net`.

Завжди дивись на кінець тексту у виводі: повний акт закінчується підписом і реквізитами. Позначка «текст показано лише частково» означає, що база відкрила тільки початок (так буває з актами Київради).

### Як знайти ID

| Вид акта | Шаблон | Приклад |
|---|---|---|
| Закон до 2000 року | `Z` + рік + номер | `Z980147` – № 147/98-ВР |
| Закон, кодекс з 2000 року | `T` + рік + номер (4 цифри) | `T222465` – № 2465-IX; `T030435` – Цивільний кодекс |
| Номер коротший за 4 цифри | через підкреслення | `T08_500` – № 500-VI; `T10_2755` – Податковий кодекс |
| Постанова Кабміну | `KP` + рік + номер | `KP981482` – № 1482 від 1998 року |
| Рішення Київради | `MR` + рік + порядковий номер бази | `MR250081` – № 76/10543 від 11.09.2025 |

Якщо шаблон не спрацював, ID є в посиланнях на акт усередині іншого акта, який на нього посилається.
