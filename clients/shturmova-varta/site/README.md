# Сайт «Штурмова варта» – робоча верстка

ТОВ «Охоронна компанія „Штурмова варта“», Київ, +380 67 549 5710.
Зверстано за погодженим макетом `../design/concept-diia-2/` (див. його `README.md`: токени, компоненти, стани, поведінка). Візуал, структура і тексти – як у макеті; що додано понад макет – нижче.

Статичний сайт: HTML + CSS + трохи JS, без бібліотек, без збірки і без бекенду. **Нічого не задеплоєно і не опубліковано.**

## Запустити локально

```bash
cd clients/shturmova-varta/site
node tools/serve.cjs 8080          # http://localhost:8080 – як на хостингу: 404.html на відсутні адреси
# або без Node: python3 -m http.server 8080 (але тоді 404 буде стандартна)
```

`index.html` і `wizard.html` відкриваються й просто з диска (подвійний клік), крім 404.

Перевірка (потрібен Playwright: `npm i -g playwright && npx playwright install chromium`):

```bash
node tools/test-site.cjs http://localhost:8080 shots/states        # 89 перевірок: майстер, надсилання, антиспам, маска, 404, SEO
node ../../../tools/screenshot.cjs http://localhost:8080/index.html shots/index   # скриншоти 360/768/1440 + report.json
```

## Що налаштувати в `js/config.js`

| Поле | Зараз | Що вписати |
|---|---|---|
| `ENDPOINT` | порожньо | адреса приймача заявок (див. «Заявки») **[уточнити]** |
| `ENDPOINT_FORMAT` | `json` | `form`, якщо приймач чекає звичайну форму |
| `EMAIL` | порожньо | e-mail для заявок – з’явиться кнопка листа з відповідями **[уточнити]** |
| `TELEGRAM_URL`, `VIBER_URL` | порожньо | канали компанії; зникне рядок «Telegram і Viber – [уточнити]…» **[уточнити]** |
| `LINE_HOURS` | порожньо | графік телефонної лінії (меню, перший екран, стан «подзвоніть») **[уточнити]** |
| `CALLBACK_TIME` | порожньо | за скільки передзвонює менеджер («Як замовити», «Заявку надіслано») **[уточнити]** |
| `LICENSE_URL` | порожньо | посилання на ліцензію у футері **[уточнити]** |
| `MIN_FILL_MS`, `TIMEOUT_MS` | 3000, 15000 | антиспам-час і тайм-аут запиту; зазвичай не чіпати |
| аналітика | закоментовано | GA4 / Meta Pixel – лише з ідентифікаторами від клієнта |

Ключів, токенів і паролів у `config.js` бути не може: файл бачить кожен відвідувач.

## Заявки

**Зараз `ENDPOINT` порожній, тож заявки онлайн не надсилаються.** Сайт цього не приховує: після «Надіслати заявку» клієнт бачить «Заявку не вдалося надіслати онлайн», номер і кнопку «Подзвонити», графік лінії і всі свої відповіді (якщо задано `EMAIL` – ще кнопку листа з відповідями). Екран «Заявку надіслано» з’являється лише тоді, коли сервер відповів 2xx.

Що надсилає майстер (POST, JSON): `service`, `service_code`, `details`, `guests`, `address`, `schedule`, `start`, `name`, `phone` (`+380XXXXXXXXX`), `channel`, `search`, `message` (усе текстом), `page`, `referrer`, `elapsed_ms`, `company` (антиспам, має бути порожнім), `utm_*`, `gclid`, `fbclid`. Помилка сервера чи тайм-аут – блок «Не вдалося надіслати заявку» з повтором і «Подзвонити», відповіді не губляться.

Антиспам у браузері: поле-пастка `company` (поза екраном, `tabindex=-1`, `aria-hidden`) і мінімальний час від відкриття майстра (`MIN_FILL_MS`). Якщо спрацювало – запит не йде, людина бачить «подзвоніть» (а не «надіслано»), тож навіть хибне спрацювання не губить клієнта. Приймач має перевіряти те саме ще раз.

Варіанти підключення (обрати з клієнтом **[уточнити]**):

1. **Formspree** (найшвидше, без коду). Створити форму на formspree.io, у `ENDPOINT` вписати `https://formspree.io/f/<id>`, `ENDPOINT_FORMAT: 'json'`. Заявки приходять на пошту. У налаштуваннях форми увімкнути reCAPTCHA/фільтр спаму на їхньому боці і обмежити домен. Безкоштовний тариф має ліміт заявок на місяць – перевірити актуальні умови.
2. **Cloudflare Worker → Telegram** (заявки в чат менеджерів, безкоштовно в межах лімітів). Приклад – `integrations/cloudflare-worker.js` (перевіряє поля на сервері, антиспам, CORS).
   ```bash
   npm i -g wrangler && wrangler login
   wrangler init zayavky   # вставити код з integrations/cloudflare-worker.js у src/index.js
   wrangler secret put TG_BOT_TOKEN      # токен від @BotFather – лише тут, не в коді сайту
   wrangler secret put TG_CHAT_ID        # id групи менеджерів
   wrangler deploy                       # ALLOWED_ORIGIN – у wrangler.toml [vars]
   ```
   У `ENDPOINT` – адреса воркера.
3. **Telegram-бот напряму з браузера – не можна**: токен бота опиниться в публічному коді. Лише через проміжний сервер (варіант 2 або власний бекенд/CRM з вебхуком).

Після підключення: надіслати тестову заявку, перевірити, що вона дійшла, і що при вимкненому приймачі сайт показує «Не вдалося надіслати заявку».

## SEO і технічне

- `title`, `description`, `canonical`, Open Graph і Twitter на головній і в майстрі; на `privacy.html` і `404.html` – `noindex`.
- **Домен невідомий [уточнити]**: усюди стоїть заглушка `https://shturmova-varta.example`. Коли буде домен: `python3 tools/set-domain.py https://справжній-домен.ua` (canonical, OG, schema.org, robots.txt, sitemap.xml).
- schema.org – `LocalBusiness` (у словнику schema.org окремого типу для охоронних компаній не знайшов): назва, юр. назва, телефон, Київ, зона обслуговування. Вулиця, ЄДРПОУ, графік, соцмережі – не вигадані, додати, коли будуть.
- `sitemap.xml` – головна і майстер; `privacy.html` додати і зняти `noindex`, коли юрист дасть текст.
- Посилання всередині сайту – `index.html`, `wizard.html` (щоб працювало з диска); дублікати `/` і `/index.html` закриває `canonical`.

## Продуктивність

- Фото: WebP + JPEG-запас через `<picture>`, `srcset` 600/1200 w, `sizes`, `width/height`, `loading="lazy"`, `decoding="async"`. Нові фото – у `img/src/`, потім `python3 tools/optimize-images.py` (потрібен Pillow) і поправити шляхи в `index.html`.
- Шрифт Onest з Google Fonts: `preconnect`, `display=swap`. Інших зовнішніх ресурсів і бібліотек немає. Скрипти – в кінці `body`, не блокують показ.
- OG-зображення й іконки перегенерувати: `node tools/make-icons-og.cjs http://localhost:8080 && python3 tools/make-favicon-ico.py`.

## Аналітика

Нічого не підключено. Місця під GA4 і Meta Pixel – закоментовані в `js/config.js`. Сайт уже викликає події (`click_call`, `click_wizard`, `wizard_step`, `lead_submit`, `generate_lead`, `lead_error`, `lead_offline`), вони запрацюють, щойно на сторінці з’явиться `gtag` чи `fbq`. Банер згоди на cookies – погодити з юристом **[уточнити]**.

## Деплой (не виконано – лише інструкція)

Підійде будь-який статичний хостинг: Cloudflare Pages, Netlify, GitHub Pages, звичайний хостинг з nginx/Apache.

1. Заповнити `js/config.js` (щонайменше `ENDPOINT`) і виконати `tools/set-domain.py`.
2. Викласти в корінь сайту: `index.html`, `wizard.html`, `privacy.html`, `404.html`, `favicon.ico`, `site.webmanifest`, `robots.txt`, `sitemap.xml`, теки `css/`, `js/`, `icons/`, `img/` (**без** `img/src/`). Не викладати: `tools/`, `integrations/`, `shots/`, `README.md`.
3. Сторінка 404: Netlify і Cloudflare Pages підхоплюють `404.html` самі; nginx – `error_page 404 /404.html;`; Apache – `ErrorDocument 404 /404.html`.
4. Увімкнути HTTPS і редирект з `www`/без `www` на один варіант; кешування для `img/`, `css/`, `js/` (після змін у CSS/JS – оновити кеш або додати `?v=2` до посилань).
5. Перед запуском – `seo-auditor`, а текст згоди й політику перевіряє юрист.
