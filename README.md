# stormclickagency

Робочий простір агенції Storm Click з набором субагентів Claude Code.

## Агенти

Файли агентів лежать у `.claude/agents/`. Claude викликає їх сам, коли завдання підходить під опис, або на пряме прохання: «використай агента ads-analyst для аудиту кампаній клієнта X».

| Агент | Напрям | Що робить |
|---|---|---|
| `content-marketer` | Маркетинг | Контент-плани, пости, сторіс, сценарії Reels, рекламні тексти |
| `ads-analyst` | Маркетинг | Аудит рекламних кампаній і звіти для клієнтів |
| `sales-proposal-writer` | Продажі | Комерційні пропозиції, брифи, відповіді на заявки |
| `market-researcher` | Продажі | Аналіз ніші, конкурентів та аудиторії |
| `ui-designer` | Розробка | Візуальний напрям, типографіка, кольори, макет сайту до верстки |
| `landing-developer` | Розробка | Верстка лендингів за макетом, форми, аналітика; перевіряє себе по скриншотах |
| `seo-auditor` | Розробка | Технічний і контентний SEO-аудит, рев'ю перед запуском |
| `ceo-strategist` | Бізнес | Бізнес-модель, стратегія, пріоритети, розбір ідей |
| `legal-counsel` | Бізнес | Договори, оферти, NDA, форма бізнесу, правові ризики (право України) |
| `financial-analyst` | Бізнес | Фінмодель, юніт-економіка, ціни, беззбитковість |
| `operations-manager` | Бізнес | Процеси, регламенти, плани проєктів, ТЗ підрядникам |
| `quality-reviewer` | Контроль якості | Незалежно перевіряє результат будь-якого агента, повертає вердикт і правки |
| `visual-reviewer` | Контроль якості | Оцінює вигляд сайту чи макета по скриншотах на 360, 768 і 1440 px |

## Конвеєр якості

Правило записане в `CLAUDE.md` і діє автоматично: виконавець робить, `quality-reviewer` перевіряє, виконавець виправляє, і так до вердикту ГОТОВО (не більше трьох кіл). Людина отримує фінал і список того, що потребує її рішення.

Для сайтів порядок такий: `ui-designer` (макет) → `landing-developer` (верстка) → `visual-reviewer` (вигляд) і `quality-reviewer` (форми, тексти, код). Скриншоти для перевірки знімає скрипт `tools/screenshot.cjs`:

```
node tools/screenshot.cjs http://localhost:5173 shots/
```

Для вже готового файлу є команда: `/polish clients/<клієнт>/reports/report-2026-11.md`.

## Структура тек

Агенти читають вхідні матеріали і зберігають результати за такою схемою:

```
agency/                  послуги, ціни, кейси агенції (для продажних матеріалів)
clients/<клієнт>/
  brief.md               бриф і tone of voice
  content/               контент-плани і пости
  ads/                   вивантаження з кабінетів і аудити
  reports/               звіти для клієнта
  research/              дослідження ринку
  seo/                   SEO-аудити
sales/<компанія>/        пропозиції та листування з лідами
projects/<проєкт>/       власні бізнеси і стартапи
  strategy/              бізнес-модель, стратегія, OKR
  finance/               фінансові моделі та розрахунки
  legal/                 договори й юридичні висновки
  processes/             регламенти і схеми процесів
  plan/                  плани проєктів і ризики
```

Що більше фактів у `agency/` і `clients/<клієнт>/brief.md`, то менше позначок `[уточнити]` буде в результатах: агенти не вигадують ціни, кейси та цифри.
